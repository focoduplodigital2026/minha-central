# Minha Central V2 — Executive Midnight

Visual escolhido: combinação dos estilos **Dark moderno** + **Executivo clean**. O arquivo `styles.css` preserva a base funcional da V1 e aplica uma segunda camada de design com fundo escuro, cartões sofisticados, cores discretas, melhor contraste e layout responsivo.

## Como experimentar

Abra `index.html` no navegador ou publique a pasta em uma hospedagem HTTPS. Todos os arquivos da pasta devem permanecer juntos.

## O que já funciona

Criação, edição, conclusão e exclusão de tarefas; áreas de Trabalho, Casa, Moto RUVA, Financeiro e Agenda; painel, filtros, calendário, recorrência ao concluir uma tarefa e armazenamento local demonstrativo.

## O que exige configuração

Login com Google, nuvem Supabase e envio/importação de eventos do Google Agenda. Leia o `README.md` para configurar. Nenhuma integração com conta foi ativada automaticamente, e esta versão ainda não envia notificações push.
